# vibe-tg : Vibe Turtle Graphics

ブラウザーでLOGOのタートルグラフィックスを動かす、静的サイト用の初期パッケージです。**ビルド不要**で、ファイル一式をGitHubリポジトリのルートに置くだけで公開できます。ブロックエディターは同梱の [Scratch Blocks](https://github.com/scratchfoundation/scratch-blocks)（`vendor/`）、AI Chat は [WebLLM](https://github.com/mlc-ai/web-llm) を CDN（jsDelivr）から読み込んでブラウザー内で動かすほか、ローカルの LLM サーバーや Claude・OpenAI・Gemini の API にもつなげます。

## GitHub Pagesで公開する

1. このZIPをダウンロードして展開します。
2. 展開したフォルダーの**中身**（`index.html`、`css/`、`js/`、`img/`、`test/`、`LICENSE`など）を、GitHubリポジトリのルートへアップロードします。ZIPファイル自体を置くだけでは公開されません。
3. GitHubのリポジトリで **Settings → Pages → Build and deployment** を開きます。
4. **Deploy from a branch** を選び、公開ブランチ（通常は `main`）とフォルダー **`/(root)`** を指定して保存します。
5. Pagesの設定画面に表示される公開URLへアクセスします。公開反映には少し時間がかかる場合があります。

> `index.html` がリポジトリの最上位にあることを確認してください。ビルド設定や独自ドメイン設定は不要です。独自ドメインを使う場合だけ、GitHub Pagesの案内に従って追加設定してください。

## ローカルで試す

Python 3がある場合は、このフォルダー内で次を実行し、`http://localhost:8000` を開きます。

```bash
python3 -m http.server 8000
```

`index.html` を直接開いた場合はコード編集だけが使えます（ブラウザーの制限で、ブロックエディターとAI Chatのモジュールを読み込めないため）。これらを試すときはローカルHTTPサーバーを使ってください。

## 使い方

- プログラム欄の **Chat／ブロック／コード** タブで編集方法を切り替えます。どこで作ったプログラムも、ほかのタブに反映されます。
- **Chat**：描きたい絵を日本語で伝えると、ブラウザー内で動くAI（Qwen などの小型モデル。メモリに余裕があれば 9B も選べます）がLOGOのコードを書き、ブロックに変換して実行します。最初に「モデルを読み込む」を押すと、モデルをダウンロードします（初回のみ、数GB）。WebGPU対応ブラウザー（Chrome / Edge の最新版）が必要です。生成したコードはブロックに変換できるか、ペンを上げたまま描こうとしていないかを検査し、だめならその理由をAIに伝えて作り直させます。直近のやり取りを覚えているので、「屋根を赤くして」のような続けての修正もできます。上部のゲージはAIに送る文脈の量（推定）で、いっぱいになると古いやり取りから外します。話題を変えるときは「新しい会話」を押してください。
- **外部のモデルを使う**（⚙ 設定の「接続先」）：ブラウザー内のモデルのほかに、次の接続先を選べます。生成中の中止は Esc キーかボタンです。
  - **ローカルサーバー**：Ollama・LM Studio・llama.cpp など、OpenAI 互換 API を出すサーバーの URL（例：`http://localhost:11434/v1`）とモデル名を入れます。「一覧を取得」でモデル名を選べ、「接続テスト」で確かめられます。公開サイトから使うときは、サーバー側でこのサイトからのアクセス（CORS）を許可してください。Ollama なら次のように起動します（文脈の長さも 8192 以上にします）。

    ```bash
    OLLAMA_ORIGINS=https://qramo.github.io OLLAMA_CONTEXT_LENGTH=8192 ollama serve
    ```

    LM Studio はサーバー設定で CORS を有効にします。Chrome では、ローカルネットワークへのアクセス許可を求められることがあります。設定の「文脈の長さ」は、サーバー側の設定と同じ値にしてください。
  - **Claude（Anthropic）・OpenAI・Gemini（Google）**：各サービスで作った API キーとモデル名を入れます。依頼文とプログラム（画像で見直すときは絵の画像も）がそのサービスに送られ、使った分の料金がかかります。使用上限を決めたキーを使ってください。キーは既定ではタブを閉じると消えます。「このブラウザーに保存する」を選ぶと保存されますが、同じサイトの他のページからも読める場所なので、共用のパソコンでは保存しないでください。
  - **考える量**：外部のモデルでは none／low／medium／high を選べます。考えるほど答えは良くなりやすい一方、時間（と料金）がかかり、考えた分も最大出力トークン数に数えます。high では最大出力を増やしてください。返事を待つ間は経過時間を表示します。
- **画像モデルでの見直し**（⚙ 設定のチェックボックス、既定はオフ）：オンにすると画像を読めるモデル（Phi-3.5-vision、VRAM 約4GB）も読み込み、描いた絵を見せて依頼どおりか確かめさせ、違っていればコード用のAIに1回だけ直させます。メモリに余裕のある環境向けです。外部のモデルでは、画像を読めるモデルなら同じモデルに絵を見せます。
- **⚙ 設定**（Chatタブ）：モデル、温度、再試行回数、システムプロンプトなどを変えられます。モデル一覧の太字は、メモリ8GB／16GB／24GB〜それぞれのおすすめです。保存済みモデルの削除もここでできます。小型モデルなので、複雑な絵はうまく描けないことがあります。
- **ブロック**：左のパレットからブロックをドラッグし、「旗が押されたとき」の下につなげます。「定義」カテゴリで自分の命令（LOGOの `to … end`）を作ると、その呼び出しブロックと引数ブロックがパレットに追加されます。
- **コード**：LOGOのプログラムを直接書きます。ブロックに変換できない書き方（未定義の命令、括弧の対応ミスなど）のときは、ブロックタブへ切り替えずに理由を表示します。
- **実行**を押すか、**Ctrl + Enter**（Macでは **⌘ + Enter**）で実行します。
- サンプル欄から図形や再帰の例を読み込めます。
- **画面を消去**は描いた絵だけを消します（プログラムは残ります）。プログラムを消すときは**コードを消去**を押します。
- 言語欄はLOGOコマンドの英語／スペイン語／日本語を切り替えます。ブロックから生成されるコードやAIが書いたコードもこの言語になります。画面の操作案内は日本語です。
- 日本語のコマンドはひらがなが基本です（`まえ 100`、`みぎ 90`、`くりかえす 4 [ … ]`、`つくる しかく :へん … おわり` など）。`前`・`右`・`繰り返す` のような漢字の別名も使えます。全角の数字・記号・スペースもそのまま使えます。定義名や変数名にも日本語が使えます。
- 実行したコードはブラウザーのローカルストレージに言語ごとに保存されます（最後に使った編集タブも保存）。外部解析は含みません。外部に送るのは、AI Chat の接続先に API を選んだときの依頼文などだけです。
- 式では `+ - * /` と括弧 `( )` が使えます。

## ファイル構成

```text
.
├── index.html
├── README.md
├── UPSTREAM.md
├── HANDOFF.md            # 開発者向けの内部メモ
├── LICENSE
├── .nojekyll
├── css/logo.css
├── img/                  # ロゴ（sea-turtle.svg）、favicon、GitHubアイコン
├── js/
│   ├── logo.js           # 上流LOGOインタプリタ（括弧対応などを追加）
│   ├── logo.i18n.js      # 上流のコマンド定義とサンプル
│   ├── site.js           # 日本語UI補助
│   ├── blocks.js         # ブロックエディター（Scratch Blocks）とタブ切り替え
│   ├── chat.js           # AI Chat（WebLLM）
│   ├── llm-worker.js     # WebLLMを動かすWeb Worker
│   ├── webllm.js         # WebLLMの読み込み先
│   ├── providers.js      # 外部モデル（ローカルサーバー、Claude、OpenAI、Gemini）への接続
│   └── pencheck.js       # AIのコードのペン上げ忘れチェック
├── test/                 # ブラウザー内テスト（ページを開くと自動実行、結果はconsole）
└── vendor/scratch-blocks/ # 同梱のScratch Blocks（Apache 2.0）
```

`css/logo.css` はレスポンシブ表示に合わせて調整しています。インタプリタ本体と言語定義、テストは上流プロジェクト由来です。出典・ライセンスの詳細は [UPSTREAM.md](UPSTREAM.md) と [LICENSE](LICENSE) を確認してください。

## カスタマイズ

- ページ名や説明：`index.html`
- 色、レイアウト、スマートフォン表示：`css/logo.css`
- 初期サンプル、操作ラベル、ショートカット：`js/site.js`
- LOGOコマンドやサンプルの追加：`js/logo.i18n.js`
- ブロックの種類・表示文言・パレット構成：`js/blocks.js`（Scratch Blocksのバージョンもここで固定しています）
- AI Chatのモデル一覧・既定のシステムプロンプト・出力文法：`js/chat.js`（WebLLMのバージョンは `js/webllm.js`）
- 外部モデルの接続先・既定値：`js/providers.js`（接続先を足すときは `index.html` の Content-Security-Policy の `connect-src` にも追加します）

実装の詳細や注意点は [HANDOFF.md](HANDOFF.md) にまとめています。

上流インタプリタの変更を取り込む場合は、既存の著作権・MITライセンス表記を残してください。
